# token数量范围过滤 (token_num_filter)

## 算子功能

这是一个Token数量过滤器，像一个智能计数器，专门统计文本被切分成多少个Token（词元），使用专业的Tokenizer（分词器）来精确统计Token数量，比简单的字数统计更准确，并根据数量范围来过滤数据。


## 处理逻辑

### 工作流程

1. **加载Tokenizer**: 使用指定的Hugging Face分词器模型
2. **文本分词**：将文本切分成Token序列
3. **统计数量**：计算Token的总数
4. **范围判断**：
   - Token数 < 最小值 → 过滤掉
   - Token数 > 最大值 → 过滤掉
   - 最小值 ≤ Token数 ≤ 最大值 → 保留
5. **输出结果**: 只保留Token数量在范围内的数据


### 示例

**配置：**
```yaml
分词器模型: 'EleutherAI/pythia-6.9b-deduped'
最小数量: 10
最大数量: 30
```

**输入数据:**
```json
[
   {"text": "你好"},
   {"text": "今天是星期天,天气很好,我们去公园玩。"},
   {"text": "人工智能正在改变世界"},
   {"text": "Python是一种编程语言"},
   {"text": "深度学习使用神经网络"}   
]
```

**输出数据:**
```json
[
   {"text": "今天是星期天,天气很好,我们去公园玩。"},
   {"text": "人工智能正在改变世界"},
   {"text": "深度学习使用神经网络"}   
]
```
